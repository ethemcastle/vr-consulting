# Website

A Next.js website starter using the app router, TypeScript, Tailwind CSS, and ESLint.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

Start editing the homepage in `src/app/page.tsx`. Global styles live in `src/app/globals.css`, and page metadata is in `src/app/layout.tsx`.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Project Structure

- `src/app/page.tsx` - homepage
- `src/app/layout.tsx` - root layout and metadata
- `src/app/globals.css` - Tailwind import and global theme styles

## Deployment

This project can be deployed anywhere that supports Next.js, including Vercel, Netlify, and Node-based hosting.
